## 🚀 Overview

InvoiceForge is a modern, responsive, and user-friendly invoice generation application built with React, TypeScript, and Vite. It allows businesses and freelancers to create, customize, and download professional invoices in PDF format with ease.

## ✨ Features

- **Modern UI/UX**: Clean, intuitive interface built with Radix UI and Tailwind CSS
- **Responsive Design**: Works seamlessly on desktop and mobile devices
- **PDF Generation**: Export invoices as professional PDF documents
- **Customizable Templates**: Multiple invoice templates to choose from
- **Client Management**: Save and manage client information
- **Product/Service Catalog**: Store and manage your products and services
- **Tax Calculation**: Automatic tax calculations
- **Dark Mode**: Built-in dark theme support
- **Form Validation**: Robust form handling with React Hook Form
- **Keyboard Navigation**: Enhanced accessibility and user experience

## 🛠️ Tech Stack

- **Frontend**: React 18, TypeScript, Vite
- **UI Components**: Radix UI, Tailwind CSS, shadcn/ui
- **Form Handling**: React Hook Form
- **PDF Generation**: jsPDF, jsPDF-AutoTable
- **Date Handling**: date-fns
- **Icons**: Lucide Icons
- **Build Tool**: Vite

## 🚀 Getting Started

### Prerequisites

- Node.js (v16 or later)
- npm (v8 or later) or yarn

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/Devansh-Kumar-Saini/SleekInvoice---Generate-Elegant-Invoices-in-Seconds.git
   cd SleekInvoice---Generate-Elegant-Invoices-in-Seconds
   ```

2. **Install dependencies**
   ```bash
   npm install
   # or
   yarn
   ```

3. **Start the development server**
   ```bash
   npm run dev
   # or
   yarn dev
   ```

4. **Open in browser**
   The application will be available at `http://localhost:5173`

## 🏗️ Building for Production

```bash
# Build the application for production
npm run build

# Preview the production build locally
npm run preview
```
